# ExamTracker · Экзамены

Нативный трекер подготовки для macOS 14 и новее. Импортирует варианты, помогает решать их с таймером и показывает прогресс по темам. Встроен пример по профильной математике ЕГЭ и набор из двух заданий по геометрии.

## Установка

Для Mac с Apple Silicon скачайте `ExamTracker-mac.zip` со страницы релиза, распакуйте архив и переместите `ExamTracker.app` в папку «Программы». Из исходников приложение можно собрать командой из раздела [«Сборка»](#сборка).

## Подготовка и тренировки

1. Нажмите **+** в боковой панели. Укажите название экзамена, итоговую шкалу, цель и максимум первичных баллов, если он предусмотрен. Темы можно ввести вручную или подобрать с ИИ.
2. В **Тренировках** откройте **Официальные варианты**. Для ЕГЭ по профильной и базовой математике, русскому, информатике и английскому официальные ZIP можно загрузить прямо из каталога. Приложение извлечёт подходящий PDF. Для некоторых иностранных экзаменов PDF также открывается в импорте напрямую.
3. В **Импорте файла** выберите PDF, ZIP, DOCX, TXT или фото. Укажите номера, например `1, 3, 6–8`, или оставьте поле пустым, чтобы взять все найденные задания. В PDF можно выбрать страницы. При импорте PDF или фото приложение прикрепляет фрагменты оригинала. Кнопка **Страницы целиком** доступна для необычной вёрстки или плохо читаемого скана.
4. Для задач без ключа приложение вычисляет ответы, когда понимает условие локально. Поддерживаются точные вычисления, простые линейные уравнения и некоторые задачи на площадь с явными размерами. Вычисленный ответ помечается в редакторе. Для ранее сохранённых наборов там же доступна кнопка **Вычислить ответы локально**. Для других самодостаточных текстовых условий можно нажать **Решить задания без ключа с ИИ** и принять подходящие ответы.
5. Откройте набор в **Тренировках**. Выберите задание в боковой панели, введите ответы и нажмите **Завершить и проверить**. Ключ и решение открываются в итогах. Сверка коротких ответов с ключом работает локально. Для развёрнутых заданий, ответов без ключа и спорных форматов выставьте балл вручную после завершения. Ноль учитывается в статистике. Ответы без балла сохраняются в истории без оценки. Таймер доступен на всём экране решения.
6. Нажмите **Записать результат**, чтобы добавить пробник. Итоговые и первичные баллы отображаются по отдельным шкалам. В настройках экзамена можно задать максимумы по умолчанию. Приложение сохраняет введённые шкалы, без автоматического перевода между ними.

В редакторе задания откройте **Точный график или фигура**. Например, введите `y = x² − 2x + 1` или `Треугольник ABC: A(0; 0), B(4; 0), C(0; 3)` и нажмите **Построить**. Для фото или скриншота выберите **Считать текст с изображения**, проверьте распознанные формулы и координаты и запустите построение. По умолчанию новая схема открывается в разборе. Для иллюстрации условия включите «Показывать схему в условии». Полные страницы и фрагменты с возможным ключом также открываются в разборе. Если на снимке только линии и подписи, его можно прикрепить как оригинал или указать параметры вручную.

## Настройки ИИ

- **Без ИИ** подходит для работы с загруженными материалами. Импорт и распознавание файлов, редактор, таймер, запись результатов и графики работают локально. Для скачивания официальных PDF нужен интернет.
- **Ollama** использует установленную локальную модель на `127.0.0.1:11434`. Выберите её в настройках. Нажмите **Обновить список**, чтобы увидеть установленные модели.
- **ChatGPT · OpenAI API** использует указанный проектный API-ключ. Введите ключ в приложении, нажмите **Сохранить ключ**, выберите модель в меню и нажмите **Проверить подключение**. Приложение сохраняет ключ в Связке ключей macOS. По умолчанию выбрана экономная `gpt-6-luna`. Для сложных задач можно выбрать GPT-6.1 Terra, GPT-6.1 Sol или ввести собственный идентификатор модели API.

ИИ вызывается только кнопками соответствующих функций. Подбор тем, генерация тренировок, разбор ошибок, извлечение баллов и краткие уроки запускаются вручную. На вкладке **Уроки** приложение составляет промпт по экзамену, теме, номеру и условию. Промпт можно просмотреть до отправки. В уроках отображаются заголовки, списки, выделения и надстрочные степени. При использовании ChatGPT галочка **Сгенерировать иллюстрацию** добавляет отдельный запрос к GPT Image с расходом квоты API. Если иллюстрация недоступна, урок сохраняется с текстом. Уроки можно читать без интернета, фильтровать по теме и заданию и сортировать. Извлечённые баллы подставляются в форму для проверки. Неуказанные значения остаются пустыми, а настроенные максимумы доступны в полях формы. В режиме ChatGPT отправляется текст выбранного запроса. Иллюстрация создаётся отдельной кнопкой через OpenAI Images API. Ответы, условия, темы и сгенерированные иллюстрации можно проверить и поправить в редакторе.

В **Claude · Anthropic API** по умолчанию выбрана экономная Claude Haiku 5.5. Для сложных уроков и разбора можно переключиться на Sonnet 5.5, Opus 5.5 или указать свой ID модели. Ключ Anthropic хранится в Связке ключей отдельно от ключа OpenAI. Для ключа, который не привязан к одной рабочей области, укажите её ID из Claude Console. Иллюстрации к урокам доступны в режиме ChatGPT.

## Сборка

Для сборки нужны macOS, Swift 6 и macOS SDK. Откройте терминал в корне проекта и выполните:

```sh
./scripts/build-app.sh
open dist/ExamTracker.app
```

Для обычного прогона тестов выполните:

```sh
swift test --disable-xctest
```

Сквозной тест распознавания формулы запускается отдельно в macOS с доступом к Vision:

```sh
EXAMTRACKER_TEST_VISION=1 swift test --disable-xctest --filter buildsGraphFromFormulaRecognizedInImage
```

## Данные и API-ключи

Экзамены, тренировки и результаты хранятся в `~/Library/Application Support/ExamTracker/exams.json`. Ключи OpenAI и Anthropic вводятся в настройках приложения и хранятся в Связке ключей macOS.

## Сборка для релиза

Соберите приложение и запакуйте его из корня проекта:

```sh
./scripts/build-app.sh
codesign --verify --deep --strict dist/ExamTracker.app
ditto -c -k --norsrc --keepParent dist/ExamTracker.app dist/ExamTracker-mac.zip
```

Прикрепите `ExamTracker-mac.zip` к релизу в GitHub Releases. Скрипт ставит локальную подпись ad hoc. Нотаризация Apple в сборку не входит.
