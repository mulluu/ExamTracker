# ExamTracker

Приложение для macOS, чтобы решать пробники и отслеживать результаты. Поддерживает все предметы ЕГЭ, IELTS Academic и General Training, TOEFL iBT, SAT и свои экзамены.

## Установка

Скачайте `ExamTracker-mac.zip` в [GitHub Releases](https://github.com/mulluu/ExamTracker/releases), распакуйте архив и перенесите `ExamTracker.app` в «Программы». Для готовой сборки нужен Mac с Apple Silicon и macOS 14 или новее. Сборка подписана локально. Инструкции по открытию приложения есть в [справке Apple](https://support.apple.com/ru-ru/102445).

## Первый запуск

1. Добавьте экзамен из шаблона или введите своё название.
2. Откройте **Тренировки → Импорт файла**. Можно выбрать официальный источник или загрузить PDF, ZIP ФИПИ, DOCX, TXT либо изображение.
3. Если в разделах повторяются номера, укажите страницы нужного раздела. Для сложной вёрстки выберите **Страницы целиком** и задайте диапазон без страниц с ответами.
4. Нажмите **Решать**. Окно можно растянуть за край или развернуть зелёной кнопкой macOS. Изображения можно свернуть. Ответы откроются после завершения.

Импорт, тренировки и история работают локально. Короткие ответы сверяются с ключом, если он есть. Для отдельных ключей можно ввести ответы в редакторе набора. Аудио и дополнительные файлы ФИПИ откройте из распакованного архива.

Свой вариант можно собрать через **Новый набор**. После подключения модели в **Настройках ИИ** доступно **Создать с ИИ** по теме или образцу.

## Сборка из исходников

Нужны Swift 6 и macOS SDK.

```sh
./scripts/build-app.sh
open dist/ExamTracker.app
swift test
```
